# SmartKids — موقع «المحرك التحليلي» وصفحة التواصل المرتبطة

موقع عربي (RTL) كامل + خادم Node.js **بدون أي اعتماديات خارجية**:
صفحة رئيسية تعرض محتوى «الفجوة بين ما يقوله الناس وما يشعرون به فعلاً» (مستويات الرصد الثلاثة، محركات العصر، وخوارزمية الرنين الرباعية)،
وصفحة **تواصل** مرتبطة فعلياً بخادم يحفظ الطلبات ويعرضها في **لوحة رسائل**.

## التشغيل

```bash
node server.js          # ثم افتح http://localhost:3000
PORT=8080 node server.js  # منفذ مخصّص
```

لا حاجة إلى `npm install` — لا توجد حزم خارجية.

## بنية المشروع

```
server.js              خادم HTTP: الملفات الثابتة + واجهات API + التخزين
public/
  index.html           الصفحة الرئيسية (المحرك التحليلي)
  physio.html          قطاع الصحة: العلاج الطبيعي والتأهيل (تفكيك الطبقات + فحص الفجوة + المسار + المؤشرات + مكتبة العناوين)
  contact.html         صفحة التواصل (نموذج مرتبط بالخادم + واتساب + بريد + ملخّص مباشر)
  inbox.html           لوحة الرسائل (مباشرة، بحث، تصفية، إحصاءات)
  404.html             صفحة الخطأ
  robots.txt  sitemap.xml
  assets/styles.css    نظام التصميم (RTL، داكن، متجاوب، طباعة)
  assets/app.js        منطق الواجهة (تحقّق، إرسال، عرض الرسائل، نقل بطاقة الفجوة)
  assets/gap-check.js  أداة فحص الفجوة (7 خطوات → بطاقة فجوة → تمريرها لنموذج التواصل)
  assets/favicon.svg
data/                  يُنشأ وقت التشغيل (messages.json + contact.log) — مستثنى من Git
```

## الربط: كيف تصل «صفحة تواصل» إلى النظام؟

```
نموذج contact.html
   └─ POST /api/contact  ──►  تحقّق من الحقول  ──►  data/messages.json  (سجل الرسائل)
                                   │                        │
                                   ▼                        ▼
                    رقم تذكرة SK-YYMMDD-XXXX        GET /api/messages ──► inbox.html
                                                    GET /api/export.md ──► تصدير Markdown
```

بعد نجاح الإرسال يظهر رقم التذكرة في الصفحة، ويُبرَز الطلب تلقائياً في لوحة الرسائل.

## واجهات API

| الطريقة | المسار | الوصف |
|---|---|---|
| `GET` | `/api/health` | حالة الخادم |
| `GET` | `/api/meta` | المجالات وأنواع الطلبات المسموحة |
| `POST` | `/api/contact` | إرسال طلب تواصل (JSON أو form-urlencoded) → يعيد `id` و`createdAt` |
| `GET` | `/api/messages` | كل الرسائل + إحصاءات؛ يدعم `?q=` للبحث و`?domain=` للتصفية |
| `GET` | `/api/messages/:id` | رسالة واحدة برقم التذكرة |
| `GET` | `/api/export.md` | تنزيل السجل كملف Markdown |

مثال:

```bash
curl -X POST http://localhost:3000/api/contact \
  -H 'Content-Type: application/json' \
  -d '{"name":"عبدالله","email":"a@b.com","domain":"مجال تقني",
       "silentPain":"الخوف من فقدان الأهمية أمام الأدوات الجديدة",
       "requestType":"تشخيص سريع (Sensemaking)","consent":true}'
```

## ما تم تنفيذه من المنطلقات

- **1) تفكيك الطبقات:** جدول «الضجيج الظاهر / المحرك السلوكي / الاستجابة الذكية» لثلاثة قطاعات (الإنتاجية، المال، الصحة).
- **2) محركات العصر:** التشتت المعرفي (Sensemaking)، الأصل والتأصيل، والحلول الأفقية المغلقة كنظام متكامل.
- **3) خوارزمية الرنين:** المسار الرباعي (مرآة → صدمة فكرية → إطار جديد → حل) معروضاً كمسار بصري وكرحلة ما بعد الإرسال.
- **صفحة التواصل:** نموذج يسأل عن «الضجيج في السوق» و«القلق غير المعلن» تحديداً — أي أنه يبني الفجوة قبل أن يطلب البيانات.
- **الربط:** التسجيل الفوري، رقم تذكرة، لوحة متابعة، وتصدير السجل.

## قطاع الصحة: العلاج الطبيعي والتأهيل (physio.html)

تطبيق كامل للمحرك التحليلي على القطاع الصحي:

- **تفكيك الطبقات:** جدول لسبع شرائح (أسفل الظهر، الرقبة، الكتف، الركبة، الإصابات الرياضية، ما بعد الجراحة، الحوض/ما بعد الولادة، التأهيل العصبي) بأعمدة: الضجيج → المحرك الخفي → الاستجابة الذكية.
- **النواة الصلبة:** ثمانية مخاوف صامتة بصياغة جاهزة للاستخدام، مع تنبيه مهني يمنع أي وعد علاجي.
- **خوارزمية الرنين:** الأبواب الأربعة بنصوص تطبيقية + مؤشر نجاح لكل باب.
- **أداة فحص الفجوة (`assets/gap-check.js`):** سبع خطوات (المنطقة، المدة، الشدة، النوم، المخاوف، الأحمال اليومية، الهدف) → «بطاقة فجوة» فيها: الضجيج السائد، القلق غير المعلن، سبب فشل النموذج السابق، ومسار من ثلاث مراحل + خطوة قابلة للتطبيق.

### كيف تُربط الأداة بصفحة التواصل؟

```
physio.html#gap-check
   └─ بطاقة الفجوة (تُبنى في المتصفح) ──sessionStorage──► contact.html
                                                          ├─ «ملف الحالة» يظهر أعلى النموذج
                                                          ├─ تعبئة تلقائية لحقلي الضجيج والفجوة
                                                          └─ POST /api/contact ► data/messages.json ► inbox.html
```

لا تُرسل أي بيانات صحية قبل ضغط المستخدم على «إرسال»؛ البطاقة تبقى في المتصفح حتى تلك اللحظة.

## ملاحظات قبل النشر

- بيانات الاتصال الحالية توضيحية: `hello@smartkids.sa` و`+966500000000` و`smartkids.sa` — استبدلها في `public/contact.html` و`public/sitemap.xml` و`public/robots.txt`.
- لوحة `/inbox.html` مفتوحة للعرض التوضيحي؛ في الإنتاج أضِف حماية (جلسة أو مفتاح وصول) + HTTPS + نسخاً احتياطياً لمجلد `data/`.
- الخادم يقبل `x-forwarded-for` لحساب حدّ المعدّل (8 طلبات/دقيقة لكل IP) ويحتوي فخّ روبوتات (حقل `website` المخفي).
